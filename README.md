# International Excellence Scholarship (IES Berlin) — Landing Page

Interactive, modern, and multilingual portal for the **International Excellence Scholarship (IES)** program organized by **Copernicus Berlin e.V.**

## 🌟 Key Features
- **Modern Responsive Design:** Inspired by modern tech products (Stripe/Linear aesthetic), featuring glassmorphic navigation, accessible typography, and smooth micro-interactions.
- **Multilingual Support:** Instant 4-language switcher:
  - 🇬🇧 English (EN)
  - 🇩🇪 Deutsch (DE)
  - 🇰🇿 Қазақша (KZ)
  - 🇷🇺 Русский (RU)
- **Interactive Eligibility Checker:** Instant real-time client-side calculation (age verification, country eligibility, study level, language proficiency).
- **Tabbed Information Architecture:**
  - *Overview* & Funding Tiers (Full, Partial Plus, Partial)
  - *What's Covered* (Detailed breakdown of allowances, accommodation, insurance, tuition)
  - *Application Timeline* (4-step admission roadmap)
  - *Partner Universities* (HU Berlin, FU Berlin, HWR Berlin, University of Potsdam)
- **FAQ Accordion:** Interactive knowledge base with WAI-ARIA accessibility support.
- **Zero Dependencies:** Pure HTML5, CSS3, and Vanilla JavaScript.

## 🚀 Live Demo / Local Setup
Simply open `index.html` in any modern web browser or serve locally:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000/`.
